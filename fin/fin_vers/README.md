# Конструктор чайной смеси

Это Android-приложение для расчета чайной смеси и отправки результата на Arduino через BLE-модуль.

Приложение позволяет выбрать 4 вида чая, задать пропорции, добавить сахар и отправить готовую строку на Arduino.

## Что нужно для работы

- Android-телефон.
- Arduino Uno или Nano.
- BLE-UART модуль, например ION, HM-10 или JDY-08.
- Установленный APK из папки `build/apk`.
- Загруженный скетч Arduino из папки `arduino/input_pr`.

## Подключение BLE-модуля к Arduino

Подключение используется такое:

```text
BLE TXD -> Arduino pin 10
BLE RXD -> Arduino pin 11
BLE GND -> Arduino GND
```

Скорость Serial Monitor:

```text
9600 бод
```

## Как пользоваться приложением

1. Установить APK на телефон.
2. Включить Bluetooth на телефоне.
3. Сопрячь BLE-модуль в настройках Bluetooth телефона.
4. Открыть приложение.
5. Ввести свое имя.
6. На экране Bluetooth выбрать модуль, обычно он называется `ION`.
7. Нажать `Подключиться`.
8. Нажать `Проверить связь`, чтобы отправить тестовую строку.
9. Если все нормально, нажать `Продолжить`.
10. Ввести названия 4 видов чая.
11. Настроить общий вес, проценты чаев и сахар.
12. Нажать `Рассчитать`.
13. Нажать `Отправить на Arduino`.

## Что отправляется на Arduino

Приложение отправляет строку такого вида:

```text
MIX:2.50,1.25,1.25,0.00;SUGAR:1.50
```

Здесь:

- первые 4 числа - граммы четырех видов чая;
- число после `SUGAR` - граммы сахара.

Arduino принимает строку, разбирает ее и выводит данные в Serial Monitor.

## Где смотреть результат на Arduino

Открыть Serial Monitor в Arduino IDE.

Настройки:

```text
Скорость: 9600 бод
```

Если данные пришли правильно, в Serial Monitor появится полученная смесь.

## Если приложение не подключается

Проверить:

- Bluetooth включен на телефоне.
- BLE-модуль сопряжен с телефоном.
- В приложении выданы разрешения Bluetooth.
- В выбранном устройстве правильный MAC-адрес.
- Arduino и BLE-модуль подключены к общему GND.
- Скорость BLE и Serial Monitor равна 9600.

## Важные файлы проекта

```text
main.py
```

Главный файл приложения и интерфейса.

```text
bluetooth_service.py
```

Формирует строку смеси и управляет Bluetooth-подключением.

```text
android_ble.py
```

Связывает Python-код с Java BLE-мостом.

```text
android_java/com/tea/mixer/ble/BleBridge.java
```

Java-код, который реально работает с Android BLE.

```text
arduino/input_pr/input_pr.ino
```

Код для Arduino, который принимает строку от BLE-модуля.

```text
build/apk
```

Папка с готовыми APK-файлами.

```text
build/build-log*.txt
```

Логи сборок APK. Их лучше не удалять, потому что они помогают искать ошибки.

## Какой APK ставить

Для большинства современных Android-телефонов нужен:

```text
tea_mixer-arm64-v8a.apk
```

Если он не подходит, можно попробовать другие APK из папки `build/apk`.
